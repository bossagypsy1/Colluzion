# Colluzion

A mobile-first, audio-reactive music video studio. Colluzion analyses a music track into control envelopes, uses them to drive GPU effects on your footage, and exports a synchronized MP4.

**Status:** Phase 1 proof of concept. See [`docs/PHASE1.md`](docs/PHASE1.md) for acceptance tests and what has been verified, and [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the design. Agent guidance is in [`AGENTS.md`](AGENTS.md).

```sh
npm ci && npm run dev
```
